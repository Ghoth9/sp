สิทธิ์เข้าใช้งาน: -

จัดการข้อมูล

สำรองข้อมูล (Export)

ดาวน์โหลดข้อมูลทั้งหมดเป็นไฟล์ JSON

นำเข้าข้อมูล (Import)

นำเข้าข้อมูลจากไฟล์ JSON ที่สำรองไว้

ล้างข้อมูลทั้งหมด

ลบข้อมูลทั้งหมดและรีเซ็ตระบบ (ไม่สามารถกู้คืนได้)

ระบบเชื่อมต่อคลาวด์ (Cloud Sync)

เปิดใช้งานโหมดคลาวด์ (Cloud Mode)

อ่านและเขียนข้อมูลไปที่ Google Sheets ในคลาวด์แทนเครื่องท้องถิ่น

URL ลิงก์ระบบหลังบ้านสำหรับเชื่อมสเปรดชีตและส่ง LINE อัตโนมัติ

ตั้งค่าขั้นสูง (แก้ไขลิงก์ระบบ)

อัปโหลดข้อมูลจากเครื่องขึ้นสเปรดชีต

กดเมื่อต้องการซิงก์ข้อมูลจากเครื่องขึ้นคลาวด์ครั้งแรก

ทดสอบส่งคิวงานเข้า LINE ทันที

ส่งรายการสรุปคิวงานของวันนี้เข้ากลุ่มช่างผ่านระบบหลังบ้าน

แชร์สิทธิ์เข้าใช้งานให้ทีมงาน

เพื่อให้ช่างคนอื่นเปิดใช้และซิงก์ข้อมูลนี้ร่วมกันได้ โดยไม่ต้องกรอก URL ยาวๆ

จัดการสมาชิกช่างแอร์ (Admin Only)

บัญชีผู้ใช้ช่างแอร์และทีมงาน

กำหนดสิทธิ์ล็อกอินและรหัสผ่านสำหรับการใช้งานแอป

ชื่อช่าง/ผู้ใช้ Username สิทธิ์ จัดการ

ติดตั้งแอปพลิเคชัน

ติดตั้งแอปพลิเคชันลงบนอุปกรณ์

เข้าใช้งานง่าย ทำงานรวดเร็ว และใช้งานแบบออฟไลน์ได้

3. กด เพิ่ม (Add) เพื่อติดตั้งเป็นแอปพลิเคชัน

ติดตั้งแอปพลิเคชัน Spairdee

ขั้นตอนสั้นๆ สำหรับติดตั้งบนอุปกรณ์ iOS

📱

กรุณาทำตามขั้นตอนต่อไปนี้ในเบราว์เซอร์ Safari:

  1. แตะปุ่ม แชร์ (Share) ในแถบเมนูด้านล่างสุด
  2. เลื่อนหน้าจอลงด้านล่าง แล้วเลือก เพิ่มไปยังหน้าจอโฮม (Add to Home Screen)
  3. แตะปุ่ม เพิ่ม (Add) ที่มุมบนขวาเพื่อเสร็จสิ้น

เมื่อติดตั้งเสร็จแล้ว ไอคอน Spairdee จะปรากฏบนหน้าจอโฮมพร้อมใช้งานทันที ❄️🛠️
